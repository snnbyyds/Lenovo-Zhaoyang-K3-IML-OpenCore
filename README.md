# Lenovo Zhaoyang K3-IML OpenCore EFI — macOS Tahoe

OpenCore EFI configuration for the **Lenovo Zhaoyang K3-IML (81M4)**.

## Status

**macOS Tahoe 26.7 (25G229) successfully boots and runs on this laptop.**

The initial EFI was generated by OpCore Simplify for macOS 26 with
SimpleHDA. Machine-specific changes were carried forward from the
[macOS 15.8 configuration](https://github.com/snnbyyds/Lenovo-Zhaoyang-K3-IML-OpenCore/tree/macOS-15)
and adjusted using observations from this laptop running Tahoe.

OpenCore and the bundled drivers and kexts use RELEASE builds. OpenCore
startup logging and verbose boot are disabled.

## Configuration Details

- **Firmware memory handling:** `EnableWriteUnprotector=true` and
  `SyncRuntimePermissions=false` accommodate this non-MAT firmware.
  `RebuildAppleMemoryMap` and `SetupVirtualMap` remain enabled. These
  settings are specific to this machine's firmware and boot behavior.
- **CPU timing:** CpuTscSync synchronizes the CPU counters. This addresses
  the early `Non-monotonic time` scheduler panic seen during the original
  macOS 15.8 bring-up.
- **USB and Bluetooth:** A machine-specific UTBMap replaces UTBDefault.
  The camera and Bluetooth connections are classified as internal.
  IntelBluetoothFirmware, IntelBTPatcher and BlueToolFixup provide the
  Bluetooth stack; `-btlfxboardid` selects the USB transport on this setup.
- **Battery and AC adapter:** SSDT-ADP1 exposes the AC adapter to macOS
  even when booting on battery power, while retaining the firmware's
  original charging and battery methods.
- **Internal display:** WhateverGreen uses both `-igfxblt` and `-igfxblr`.
  The classic backlight register fix resolved the prolonged black screen
  between the Apple logo and the login screen.
- **Discrete GPU power:** SSDT-DGPU-OFF calls the firmware's
  `\_SB.PCI0.RP05.PEGP._OFF` method during macOS initialization and after
  the original wake method. It retains the OEM power sequence, polarity
  checks and timing. After boot, the firmware power-enable signal was
  observed changing from active to inactive, confirming more than driver
  suppression. This is not a physical rail-voltage measurement;
  sleep/wake behavior still needs verification. The SSDT source is in
  [Sources/SSDT-DGPU-OFF.dsl](Sources/SSDT-DGPU-OFF.dsl).
- **NVMe power management:** NVMeFix is retained, with ASPM L1 requested
  through `pci-aspm-default` on the verified SSD and its upstream bridge.
  This does not establish support for deeper CPU package idle states.
- **Touchpad:** The forced VoodooI2C polling argument is removed so the
  driver can select the available interrupt resources. The touchpad has
  been confirmed working by the user.
- **Audio:** AppleALC uses ALC257 layout ID `100`, together with SimpleHDA
  for Tahoe. Speaker and headphone playback work, with the output
  selection limitation described below.

## Known Issues

- The built-in Intel SST digital microphone is not working.
- After boot, the default audio output selects **Headphones** even when
  no headphones are connected. For speaker playback, manually select
  **Internal Speakers** in **System Settings → Sound → Output**. Both
  speaker and headphone playback work when the appropriate output is
  selected; automatic output selection is still under investigation.
